1. Reverse an Array
   Reverse the given array in-place using two pointers.

Input: [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]

2. Valid Palindrome
   Check whether the given string is a palindrome.

Input: "madam"
Output: true

Input: "hello"
Output: false

3. Two Sum II
   Given a sorted array and a target, find two numbers whose sum equals the target.

Input: arr = [2, 7, 11, 15], target = 9
Output: [1, 2]

4. Move Zeroes
   Move all zeroes to the end of the array while maintaining the relative order of non-zero elements.

Input: [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]

5. Remove Duplicates
   Given a sorted array, remove duplicates in-place.

Input: [1, 1, 2, 2, 3]
Output: [1, 2, 3]

6. Remove Element
   Remove all occurrences of a given value from an array in-place.

Input: arr = [3, 2, 2, 3], value = 3
Output: [2, 2]

7. Merge Two Sorted Arrays
   Merge two sorted arrays into one sorted array.

Input:
A = [1, 3, 5]
B = [2, 4, 6]

Output: [1, 2, 3, 4, 5, 6]

🟡 Medium

8. Squares of a Sorted Array
   Given a sorted array containing negative and positive numbers, return the squares in sorted order.

Input: [-4, -1, 0, 3, 10]
Output: [0, 1, 9, 16, 100]

9. Container With Most Water
   Given an array representing heights of vertical lines, find the maximum amount of water a container can hold.

Input: [1, 8, 6, 2, 5, 4, 8, 3, 7]
Output: 49

10. 3Sum
    Find all unique triplets whose sum is 0.

Input: [-1, 0, 1, 2, -1, -4]
Output:

[[-1, -1, 2], [-1, 0, 1]]

11. Sort Colors
    An array contains only 0, 1, and 2. Sort the array in-place.

Input: [2, 0, 2, 1, 1, 0]
Output: [0, 0, 1, 1, 2, 2]

12. Backspace String Compare represents a backspace. Determine whether two strings are equal after applying the backspaces.

Input:

s = "ab#c"
t = "ad#c"

Output:

true

13. Valid Palindrome II
    Determine whether a string can become a palindrome after deleting at most one character.

Input: "abca"
Output: true

Input: "abc"
Output: false

14. Sort Array by Parity
    Move all even numbers to one side and odd numbers to the other side.

Input: [3, 1, 2, 4]
Output: [4, 2, 1, 3]

Any valid arrangement is acceptable.

🔴 Hard

15. Trapping Rain Water
    Given an array representing elevation heights, calculate how much rainwater can be trapped.

Input:

[0,1,0,2,1,0,1,3,2,1,2,1]

Output:

6

16. 4Sum
    Find all unique quadruplets whose sum equals the target.

Input:

nums = [1,0,-1,0,-2,2]
target = 0

Output:

[[-2,-1,1,2],
[-2,0,0,2],
[-1,0,0,1]]

17. Longest Substring Without Repeating Characters
    Find the length of the longest substring without duplicate characters.

Input: "abcabcbb"
Output: 3

18. Minimum Size Subarray Sum
    Find the minimum length of a contiguous subarray whose sum is greater than or equal to the target.

Input:

target = 7
nums = [2,3,1,2,4,3]

Output:

2

19. Subarray Product Less Than K
    Count the number of contiguous subarrays whose product is less than k.

Input:

nums = [10,5,2,6]
k = 100

Output:

8

20. Minimum Window Substring ⭐
    Find the smallest substring of s that contains all characters of t.

Input:

s = "ADOBECODEBANC"
t = "ABC"

Output:

"BANC"
